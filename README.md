# N-Queen Problem

This repository contains multiple algorithms to solve the N-Queen Problem:

- Depth-First Search (DFS)
- Greedy Search (Hill Climbing)
- Simulated Annealing
- Genetic Algorithm

## Files
- `DFS.py`: DFS-based solution
- `GreedySearch.py`: Greedy/Hill Climbing solution
- `SimulatedAnnealing.py`: Simulated Annealing solution
- `GeneticAlgorithm.py`: Genetic Algorithm solution

## Usage
Each script can be run from the command line. For example:

```bash
python DFS.py 8
python GreedySearch.py 8
python SimulatedAnnealing.py 8
python GeneticAlgorithm.py 8
```

If no argument is provided, the script will prompt for N.
